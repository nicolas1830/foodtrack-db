# FoodTrack DB

Base de datos relacional para gestionar las operaciones de una plataforma
de foodtrucks en distintos puntos de una ciudad.

## Objetivo

El proyecto consiste en diseñar e implementar una base de datos relacional
utilizando Microsoft SQL Server.

La base de datos permitirá gestionar información relacionada con:

- Foodtrucks
- Productos
- Pedidos
- Detalle de pedidos
- Ubicaciones

## Tecnologías utilizadas

- Microsoft SQL Server
- DBeaver
- Git
- GitHub
- Python
- pyodbc
